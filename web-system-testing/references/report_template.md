# 测试报告模板说明

## 概述

标准化测试报告包含四个Sheet，必须严格按照以下结构生成。

---

## Sheet 1: 测试概要

### 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | 第X轮测试报告 - {模块名} |
| 测试时间 | 日期 | YYYY-MM-DD格式 |
| 测试模块 | 文本 | 模块名称 |
| 测试类型 | 文本 | 功能全面测试/回归测试/冒烟测试 |
| 功能点总数 | 数字 | 总功能点数量（不同功能点的去重数量） |
| 测试结果统计 | 分隔行 | - |
| 总功能点数 | 数字 | 与功能点总数一致 |
| 已测试 | 数字 | 实际执行测试的用例条数 |
| 通过 | 数字 | 测试通过的用例条数 |
| 失败 | 数字 | 测试失败的用例条数 |
| 阻塞 | 数字 | 无法测试的用例条数 |
| 通过率 | 百分比 | 通过/已测试 |
| 阻塞功能点 | 文本 | 如有阻塞，描述具体问题 |

---

## Sheet 2: 详细测试结果

### 列定义（共13列）

**【重要】每个功能的增、查、改、删操作必须分行记录**

| 列序号 | 列名 | 说明 |
|--------|------|------|
| 1 | 序号 | 从1开始递增 |
| 2 | 用例ID | 格式：TC-XXX，与截图名称中的用例ID一致 |
| 3 | 功能点 | 功能名称（中文） |
| 4 | 操作类型 | 新增/查看/编辑/删除/审核（中文） |
| 5 | 优先级 | P0/P1/P2 |
| 6 | 操作步骤 | 详细的操作步骤（中文），每步必须包含：点击的具体按钮名称、填写/修改的字段及具体值、选择的选项、操作顺序编号 |
| 7 | 预期结果 | 期望的系统行为（中文），包含具体的提示信息、界面变化、数据验证等 |
| 8 | 实际结果 | 实际观察到的系统行为（中文），包含实际提示信息、界面变化、数据状态等 |
| 9 | 测试时间 | 格式：YYYY-MM-DD HH:MM |
| 10 | UI测试 | 记录布局/元素异常情况，无异常写"无"，有异常详细描述 |
| 11 | 性能测试 | 记录操作响应时长（毫秒），如"1250ms"，无需判定通过/不通过 |
| 12 | 截图名称 | 截图文件名，格式：TC-XXX_功能点_操作类型.png（与用例ID一致） |
| 13 | 备注 | 异常情况说明（中文），如不适用原因等 |

### 记录规则

- **每个功能点的每种操作类型必须单独记录一行**
- 操作步骤必须包含完整的数据操作（填写→保存→验证），禁止"点到为止"
- 记录预期结果和实际结果
- 操作类型列必须设置对应底色

### 操作类型底色规则

| 操作类型 | 底色 | 颜色代码 |
|----------|------|----------|
| 新增 | 浅绿色 | `90EE90` |
| 查看 | 浅蓝色 | `ADD8E6` |
| 编辑 | 浅黄色 | `FFFACD` |
| 删除 | 浅红色 | `FFB6C1` |
| 审核 | 浅橙色 | `FFDAB9` |
| 不适用 | 浅灰色 | `D3D3D3` |

### 样式规则

- 表头背景色: #4472C4（蓝色）
- 表头字体: 白色，粗体
- 操作类型单元格底色: 根据操作类型设置（见上方底色规则）
- "通过"状态: #C6EFCE背景，#006100绿色字体
- "失败"状态: #FFC7CE背景，#9C0006红色字体
- "阻塞"状态: #FF0000背景，白色字体

## Sheet 3: Bug列表

### 列定义（共9列）

| 列名 | 说明 |
|------|------|
| Bug ID | 格式：BUG_XXX（如BUG_001） |
| 用例ID | 对应的测试用例ID（如TC-001） |
| 功能点 | 出问题的功能名称（中文） |
| 严重程度 | 阻塞/严重/一般/低（中文） |
| 问题描述 | 详细描述问题现象（中文） |
| 预期结果 | 期望的系统行为（中文） |
| 实际结果 | 实际观察到的行为（中文） |
| 状态 | 待确认/待修复/已修复/已关闭（中文） |
| 建议 | 修复建议（中文） |

### 严重程度说明

| 等级 | 说明 | 背景色 |
|------|------|--------|
| 阻塞 | 无法继续测试 | #FF0000 |
| 严重 | 功能不可用 | #FFC7CE |
| 一般 | 功能可用但有问题 | #FFEB9C |
| 低 | 界面/体验问题 | #C6EFCE |

## 输出文件命名规范

└── 第X轮测试详细报告_{模块名}_{YYYYMMDD}.xlsx
